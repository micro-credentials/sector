# Micro-Credentials Sectors

This is repository contains the `Sectors` for which the `Micro-Credentials` are developed. 

## Sector

A `sector` is a large grouping of jobs, businesses, and economic activities categorized by the primary type of work, service, or product they produce.  

A sector is further subdivided into `Functional Groups`. A functional group represents a role that perform the same core business function or specialized operational tasks.

Sectors and Functional Groups classifications are in accordance with the following standard:

[International Standard Industrial Classification (ISIC) Rev. 5](https://unstats.un.org/unsd/classifications/Econ/Download/ISIC_Rev5_Publication-white_cover_version.pdf)
